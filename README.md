Реализация in-memory базы данных на Python с поддержкой нескольких таблиц и полного набора CRUD операций. В качестве предметной области выбрана **библиотечная система** с таблицами:

- **books** - информация о книгах
- **readers** - информация о читателях
- **loans** - выдачи книг
## Структура проекта
src/
└── db/
├── init.py # Маркировка пакета
├── main.py # Точка входа в приложение
├── tui.py # Текстовый пользовательский интерфейс
└── backend/
├── init.py # Маркировка пакета
└── memory.py # Реализация in-memory БД

### Назначение модулей

- **memory.py** - управление таблицами, CRUD операции, валидация данных
- **tui.py** - пользовательский интерфейс: меню, ввод/вывод, взаимодействие с пользователем
- **__main__.py** - точка входа, запуск интерфейса
### Операции с данными (CRUD)

1. **Create (Создание)**
   - Добавление книг, читателей, выдач
   - Автоматическая генерация ID
   - Валидация данных по схеме

2. **Read (Чтение)**
   - Просмотр всех записей
   - Фильтрация по одному или нескольким полям
   - Пагинация (limit/offset)
   - Поиск по ID

3. **Update (Обновление)**
   - Изменение любого поля записи
   - Автоматическая синхронизация связанных данных (например, статуса книги при выдаче/возврате)

4. **Delete (Удаление)**
   - Удаление по ID
   - Каскадное удаление связанных записей
   - Удаление по фильтру

### Обработка ошибок

- Некорректный ввод данных (ValueError)
- Обращение к несуществующим таблицам/записям
- Нарушение уникальности ID
- Несоответствие схеме таблицы
- Пользовательские исключения: `DatabaseError`, `TableNotFoundError`, `RecordNotFoundError`, `ValidationError`

### Текстовый интерфейс

- Главное меню с выбором действий
- Интерактивные формы ввода данных
- Подсказки и инструкции
- Просмотр результатов с форматированием
