## Описание проекта

Объектно-ориентированная реализация in-memory базы данных на Python с поддержкой нескольких таблиц, полного набора CRUD операций и сортировки. В качестве предметной области выбрана **библиотечная система**.

### Назначение модулей

| Файл | Назначение |
|------|------------|

## Функциональность

### Основные возможности

1. **Управление таблицами**
   - Создание таблиц с заданной схемой
   - Удаление таблиц
   - Получение информации о таблицах

2. **CRUD операции**
   - **Create** - создание записей с автоинкрементом ID
   - **Read** - чтение с фильтрацией, сортировкой и пагинацией
   - **Update** - обновление записей с валидацией
   - **Delete** - удаление по ID или по фильтру

3. **Сортировка**
   - По любому полю таблицы
   - По возрастанию или убыванию

4. **Фильтрация**
   - По одному или нескольким полям
   - Точное совпадение значений

5. **Валидация данных**
   - Проверка типов полей
   - Проверка наличия обязательных полей
   - Уникальность ID

### Обработка ошибок

Пользовательские исключения:
- `DatabaseError` - базовое исключение
- `TableNotFoundError` - таблица не найдена
- `TableExistsError` - таблица уже существует
- `RecordNotFoundError` - запись не найдена
- `DuplicateIDError` - дублирующийся ID
- `ValidationError` - ошибка валидации
- `InvalidFieldError` - некорректное поле
- `InvalidSortError` - ошибка сортировки
