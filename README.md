# Библиотечная система с поддержкой файлового хранения

## Структура проекта

## Функциональность
- Создание/удаление таблиц
- CRUD операции над записями
- Фильтрация и сортировка
- Два режима хранения: in-memory и файловый (JSON)
- Данные сохраняются между запусками в файловом режиме
