# Библиотечная система

## Описание проекта

Программа для управления библиотекой с поддержкой двух типов хранения данных:
- **In-memory** - данные хранятся только в оперативной памяти
- **File-based** - данные сохраняются в JSON файлы на диске

Функциональность:

Создание таблиц (книги, читатели, выдачи)

Добавление/просмотр/обновление/удаление записей

Фильтрация по любому полю

Сортировка по выбранному полю

Возврат книг с обновлением статуса

Валидация данных

Обработка ошибок ввода

## Различия между in-memory и файловой реализациями

| Характеристика | In-memory | File-based (JSON) |
|----------------|-----------|-------------------|
| Хранение данных | Оперативная память | Файлы на диске |
| Сохранение после выхода | Нет | Да |
| Скорость работы | Высокая | Средняя |
| Папка с данными | Не требуется | `data/` |
| Формат файлов | Нет | `.json` |
| Подходит для | Тестирование | Реальное использование |

### Требования:

- Python 3.10 или выше
  
## Запуск программы:

```bash
python -m src.db
```
## Запуск тестов:
```bash
python -m pytest tests/ -v
```
## Проверка покрытия:
```bash
python -m pytest tests/ --cov=src --cov-report=term
```
